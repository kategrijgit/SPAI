# SPAI
First study project with Artemsy and Mishas 

## Repository structure

- `frontend/` - frontend application
- `backend/` - backend application
- `db/` - database scripts and related files
- `docs/api.md` - API documentation

## Branch protection

Protect `main` in GitHub under **Settings > Branches > Add branch protection rule**. Require pull requests before merging and at least one approval, and disable direct pushes by requiring changes to go through a pull request.
